## Stricter A bar

One command must be able to transform current exact-engine evidence into a deterministic single-canvas replay, verify spatial stability and input parity, capture every critical state, enforce real performance budgets without fallback loopholes, compare a candidate to its approved baseline, identify the responsible module, and record one ranked next action. Every canonical automated scenario must reach a terminal outcome and every experiment must end in an honest accepted, rejected, or inconclusive decision.
