# Improvement System Implementation Checklist

This checklist is both the implementation record and the source for the portfolio's recommendation-completion metric.

- [x] Define one versioned quality contract across gameplay, UX, art, marketing, reliability, release, player validation, and improvement operations.
- [x] Give every surface an owner, objective, weight, current grade, evidence contract, and stricter A bar.
- [x] Detect affected surfaces from changed files.
- [x] Select and deduplicate proportionate quick and full verification commands.
- [x] Generate one internal portfolio and one compact privacy-safe public snapshot.
- [x] Track evidence presence, freshness, minimum human-observation counts, grade caps, and confidence.
- [x] Compare each snapshot with a saved baseline and keep bounded history.
- [x] Rank one cross-surface next action by failure and evidence severity.
- [x] Add experiment, decision, and consent-safe playtest ledgers.
- [x] Enforce legal candidate promotion transitions with evidence and a decision.
- [x] Measure diagnosis time, regression rate, verification coverage, evidence freshness, change-to-evidence rate, recommendation completion, and observed playtests.
- [x] Register specialist reports and identify stale or superseded retirement candidates without deleting them.
- [x] Add automated tests for routing, evidence, scoring, promotion, output, and retirement behavior.
- [x] Document the daily, hard-gate, record, and promotion workflows.
- [x] Turn the default improvement command into a bounded diagnose-repair-verify-regrade loop.
- [x] Register deterministic repair recipes for generated gameplay, UI, marketing, SEO, and verification evidence.
- [x] Add dry-run planning, risk ceilings, iteration limits, no-repeat protection, and a concurrent-run lock.
- [x] Detect undeclared Git-visible writes and stop the repair loop on policy violations.
- [x] Emit an auditable apply report and assisted repair packet when judgment or human observation is required.
- [x] Provide changed-surface, explicit-scope, and all-surface apply modes.
- [ ] Record five recent representative human playtest sessions covering first play and return play.
- [ ] Add the hard control-plane gate to CI when the repository's CI policy is restored.
